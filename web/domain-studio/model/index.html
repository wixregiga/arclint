Boundaries of meaning. Overlapping sets of files.

Library gives “Book” a different meaning in Catalog and Circulation. Inspect the regions, then the files and Zones. Map and Table use the same references. This board explains the proposed model; it is not the application's next UI.

What the boundary means

A context contains a local model. An aggregate, when recorded, is a consistency enclosure inside it. These describe concept types and contracts, not live people, objects or events.

What the overlay means

A Zone selects files through path globs. “audited” includes both Book files and a file without a context association. The contexts and definitions stay unchanged.

What the arrows mean

Catalog → Circulation is recorded influence. That conformist relation allows the reverse import direction. This example supplies no observed imports and no Report; neither is invented from the diagram.

Where Onyx belongs

One persistent support avatar belongs to the interface, outside the model. She helps with the current question and selection. Her presence does not establish ownership, authority or an evaluation result.
