## Architecture contracts (arclint)

Enforced from rules.yaml: 24 rules over languages [go, typescript]. Before editing under
a path, run `arclint context <paths...>` for the modules and rules that bind it.
Verify changes with `arclint check .`.

### Modules

- **application** — Action-named use cases coordinating domain objects through ports. (paths internal/application/**; internal imports allow: domain; external forbid)
- **cli_factory** — Sealed CLI factory selecting an adapter by ArcLint-owned identity. (paths internal/delivery/cli/factory/**; internal imports allow: application, domain, cobra_adapter, delivery; external forbid)
- **cobra_adapter** — The only package permitted to import Cobra. (paths internal/delivery/cli/adapters/cobra/**; internal imports allow: application, domain, delivery)
- **composition** — Composition roots selecting and connecting concrete adapters. (paths cmd/**; internal imports allow: delivery, infrastructure, application, domain, cli_factory, cobra_adapter)
- **conformance** — The conformance bounded context, downstream conformist of rule. (paths internal/domain/conformance/**)
- **delivery** — Inbound adapters translating external input into application requests. (paths internal/delivery/**; internal imports allow: application, domain)
- **domain** — Rule aggregate and domain values; stdlib-only. (paths internal/domain/**; internal imports none (may import no other declared module); external forbid)
- **infrastructure** — Outbound technology adapters implementing inward-owned ports. (paths internal/infrastructure/**; internal imports allow: application, domain)
- **rule** — The rule bounded context: the Rule aggregate's home. (paths internal/domain/rule/**)
- **source** — Common source invariants for internal packages. (paths internal/**)
- **vocabulary** — The project's recorded Ubiquitous Language vocabulary. (paths ubiquitous-language.yaml)

### Query commands

- `arclint context [paths...]` — the architecture, or everything binding the given paths (`--module <names>`, `--format json`)
- `arclint rules [selector]` — the configured rules; one match shows the complete Rule
- `arclint check .` — evaluate every rule; exit 1 on error-severity findings

## Finish gate

Before yielding a completed session or goal, run:

```bash
make check-fix
```

or the same pair through mise:

```bash
mise run check-fix
```

For read-only sessions (reviews, audits, anything that must not mutate
the tree), the gate is the non-mutating, network-free variant:

```bash
make check-ro
```
